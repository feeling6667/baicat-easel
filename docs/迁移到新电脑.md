# 迁移到新电脑

> 这份文档说明：**这台电脑上定制过的 Easel，怎么搬到另一台电脑。**
>
> 原则：
> - **代码 + 技能 + 内容** 跟着这个 git 仓库走。
> - **运行环境**（Node / Python / ffmpeg / openclaw）**不带**，在新电脑上联网下载。
> - **密钥**（`.env`、`openclaw.json` 里的 API Key）**不带**，在新电脑上重新填。
> - **magpie 中转**（`D:\Magpie`）**不带**，在新电脑上自己装。

---

## 一、新电脑要装的东西（含版本）

| 组件 | 本机版本 | 怎么装 |
|---|---|---|
| Git | `2.55.0` | https://git-scm.com/download/win |
| **Node.js** | **`24.21.0`** | 见下方「Node 的坑」 |
| **Python** | **`3.13.14`** | https://www.python.org/downloads/（安装时勾 **Add Python to PATH**） |
| ffmpeg | `9.0.1`（gyan.dev essentials） | https://www.gyan.dev/ffmpeg/builds/ 解压后把 `bin` 目录加进 PATH |
| **openclaw** | **`2026.9.4`** | `npm i -g openclaw@2026.9.4` ⚠️ **别装 latest** |
| Playwright Chromium | `1.63.0` | 跑 `setup.ps1` 会自动装 |

### Node 的坑

**openclaw 要求 Node `>=24.16.0 <25`**（25.x 和 26.0 都不行）。

如果新电脑**没有管理员权限**，`winget` 装不了系统包。这时手动装便携版：

1. 打开 https://nodejs.org/dist/v24.21.0/
2. 下 `node-v24.21.0-win-x64.zip`
3. 解压到任意目录（本机是 `C:\Users\Administrator\.easel-tools\node24\`）
4. 把该目录加进用户级 PATH

> 本机就是这么装的（`.easel-tools\node24`），Easel 的 openclaw 也装在这个目录下的 `node_modules`。

## 二、还原步骤

```
1. git clone <你的私有仓库地址>
2. 把 .env.example 复制成 .env，按「三」填好
3. 手工补网关配置（见「四」）
4. 跑 setup.ps1 —— 自动装 Python 依赖、构建网页、装浏览器、初始化 profile
5. 装 magpie 中转（见「五」）
6. 双击 start-easel.cmd 启动
```

> ⚠️ **路径问题**：本机的配置里有很多 `C:\Users\Administrator\...` 的绝对路径。
> 如果新电脑的**用户名不是 Administrator**，这些路径要改（主要在 `~\.openclaw-easel\openclaw.json` 的 `workspace` / `agentDir` 字段）。

## 四、网关配置要手工补的（`~\.openclaw-easel\openclaw.json`）

`setup.ps1` 会初始化一个默认网关配置，但**下面这几项是本机手动加的，setup 不会带过去**，不补会踩以前踩过的坑：

```jsonc
{
  "gateway": {
    "port": 18789,
    "http": {
      "endpoints": {
        "chatCompletions": { "enabled": true }   // ⚠️ 不开这个，每轮对话都要冷启动，很慢
      }
    }
  },
  "agents": {
    "defaults": {
      "model": { "primary": "magpie/clinepass/cline-pass/glm-5.3-flash" }   // 按新电脑实际的中转模型改
    }
  },
  "models": {
    "providers": {
      "magpie": {
        "api": "openai-completions",
        "baseUrl": "http://127.0.0.1:3425/v1",   // magpie 中转地址
        "apiKey": "<自己填>",
        "models": [ { "id": "clinepass/cline-pass/glm-5.3-flash", "name": "GLM-5.3-Flash (clinepass)", "reasoning": false, "input": ["text"] } ]
      }
    }
  }
}
```

> 本机的 `openclaw.json` **含 API Key，所以不在这个仓库里**，需要在新电脑上手工重建（或从旧电脑单独拷）。

### 关于 `--raw-stream`

启动网关时的 `--raw-stream` 参数**已经在代码里**（`scripts/gateway.ps1`），不用手工加。
它的作用是让网页能实时看到"正在思考"的流式输出，不加会一直卡在"正在思考…"。

## 五、magpie 中转（不在本仓库，新电脑自己装）

本机的模型调用走本地中转：

```
http://127.0.0.1:3425/v1
```

- 装在哪：`D:\Magpie`
- 用途：把各家的模型统一成一个接口，Easel 通过它调模型
- **新电脑必须也装一份并跑起来**，否则 `.env` 和 `openclaw.json` 里的模型地址会指向空气，对话直接报错。

## 六、没带过来的东西（清单）

| 没带 | 原因 | 新电脑怎么办 |
|---|---|---|
| `.env` | 含 5 个 API Key | 按「三」重新填 |
| `openclaw.json` | 含 API Key | 按「四」重建 |
| `profiles/*/` | 含公众号/小红书登录凭证 | 在新电脑上重新扫码登录 |
| `.venv` | 1.3G，可重建 | `setup.ps1` 自动装 |
| `node_modules` | 88M，可重建 | `setup.ps1` 自动装 |
| `.easel-tools/` | 3G（node24 + ffmpeg + 其他） | 按「一」重新下载 |
| magpie | 本地中转服务 | 按「五」自己装 |
| 各种 `*.bak.before-*` | 旧备份，含密钥 | 不需要 |

## 七、本机定制的改动概览（相对官方 Easel）

主要是这几块：

1. **网页界面**：输入框旁的模型下拉（`ModelPicker`）、内容日历条目一键打开产出物、侧边栏与对话页若干调整
2. **网关与启动**：`scripts/gateway.ps1` 加 `--raw-stream`；新增 `scripts/easel-start.ps1`、`easel-stop.ps1`、`start-easel.cmd`（桌面快捷方式用）
3. **自检脚本**：`scripts/check_raw_stream.py`（查原始流与默认模型）、`scripts/is_web_stale.py`（查网页是不是旧代码）
4. **后端**：`web/app.py` 的模型选择、原始流路径、HTTP 模型头等修复
5. **技能库**：新增 10 个 `dbs-*` 技能（来自 [dontbesilent2025/dbskill](https://github.com/dontbesilent2025/dbskill)，**CC BY-NC 4.0 非商业许可**，勿用于商业分发）
